# منصة الرخصة المهنية — الاختبار العام

منصة عربية متكاملة للتدريب والمذاكرة والاختبارات المحاكية لاختبار **الرخصة المهنية للمعلمين (الاختبار العام)** الصادر عن هيئة تقويم التعليم والتدريب. تغطي المجالات الثلاثة للاختبار العام: **الكفايات التربوية، الكفايات الكمية، والكفايات اللغوية**، مع أكثر من **315 سؤالاً مؤلّفاً بالشرح المفصل**، وملخصات مركّزة لكل موضوع، واختبارات محاكية موقوتة، وتتبع دقيق للتقدم.

> بُنيت هذه المنصة للأغراض التعليمية، وهي غير رسمية ولا تتبع أي جهة حكومية. لاحقاً ستُضاف اختبارات وتدريبات **التخصصات** إلى جانب الاختبار العام.

## المزايا

- **📖 مذاكرة**: ملخصات منهجية لكل موضوع (نظريات التعلم، التخطيط، التقويم، النسب، الهندسة، الإحصاء، الإملاء، النحو، الترقيم، الفهم القرائي…).
- **✏️ تدريب مخصّص**: اختر المجال/الموضوع ومستوى الصعوبة وعدد الأسئلة، بشرح فوري بعد كل إجابة.
- **⏱️ اختبار محاكاة**: 88 سؤالاً في ساعتين (أو صيغ أقصر) تحاكي الاختبار الحقيقي بمؤقّت تنازلي وتوزيع مرجّح على المجالات.
- **🔁 بنك الأخطاء**: تُجمع الأسئلة الخاطئة تلقائياً لمراجعتها حتى إتقانها.
- **📊 تتبع التقدم**: نسبة الإتقان لكل مجال وموضوع، سجل الجلسات، أفضل نتيجة، والأيام المتتالية.
- **👤 حساب اختياري**: تدرّب كزائر (البيانات محفوظة محلياً)، أو سجّل الدخول لمزامنة تقدمك عبر أجهزتك.
- **🌙 الوضع الليلي** ودعم كامل للاتجاه من اليمين لليسار (RTL).

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Vite |
| التصميم | Tailwind CSS v4 (RTL) |
| التوجيه | React Router |
| قاعدة البيانات والمصادقة | Supabase (Postgres + Auth + RLS) |
| الاستضافة | Netlify |

المحتوى (الأسئلة والملخصات) مُضمَّن في التطبيق (`src/data/bank.json`) ليعمل بسرعة وبلا اتصال، بينما تُستخدم Supabase للمصادقة وحفظ محاولات المستخدمين، كما تُخزَّن نسخة من المحتوى في قاعدة البيانات لإدارته والتوسع مستقبلاً.

## التشغيل محلياً

```bash
npm install
npm run dev          # خادم التطوير
npm run build        # بناء الإنتاج إلى dist/
npm run preview      # معاينة بناء الإنتاج
```

### متغيرات البيئة

القيم الافتراضية لـ Supabase مضمّنة في `src/lib/supabase.ts` (مفتاح publishable آمن للواجهة). لتجاوزها انسخ `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

## قاعدة البيانات (Supabase)

المخطط في `supabase/migrations/0001_schema.sql`. الجداول (ببادئة `pl_`):

- `pl_sections` — مجالات الاختبار الثلاثة.
- `pl_topics` — مواضيع كل مجال مع ملخصاتها.
- `pl_questions` — بنك الأسئلة (نص، خيارات JSON، الإجابة، الشرح، الصعوبة).
- `pl_attempts` — محاولات المستخدمين (محمية بـ RLS: كل مستخدم يرى محاولاته فقط).

المحتوى قابل للقراءة العامة، والكتابة على المحتوى مقصورة على لوحة Supabase. محاولات المستخدمين محمية بسياسات RLS تربط كل صف بـ `auth.uid()`.

### إعادة توليد البيانات وتعبئتها

```bash
# توليد bank.json وملفات الـ SQL من ملفات data/
npm run seed:bank

# تعبئة قاعدة البيانات (من جهاز له وصول شبكي إلى Supabase)
SUPABASE_URL=... SUPABASE_ANON_KEY=... node scripts/seed-supabase.mjs
```

بدلاً من ذلك، يمكن لصق ملفات `supabase/seed/*.sql` مباشرة في محرر SQL في لوحة Supabase.

## النشر على Netlify

الإعدادات في `netlify.toml` (أمر البناء `npm run build`، مجلد النشر `dist`، وإعادة توجيه SPA). للنشر:

1. اربط المستودع بـ Netlify (أو `netlify deploy --prod`).
2. (اختياري) عيّن `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في متغيرات البيئة.

## بنية المشروع

```
data/                 # مصدر المحتوى (أقسام، مواضيع بالملخصات، أسئلة)
scripts/              # توليد bank.json + الـ SQL، وتعبئة Supabase
supabase/
  migrations/         # مخطط قاعدة البيانات
  seed/               # بيانات التعبئة (SQL)
src/
  components/         # مكونات واجهة قابلة لإعادة الاستخدام
  context/            # حالة التطبيق (مصادقة، مظهر، محاولات)
  lib/                # المنطق: البنك، Supabase، الجلسات، الإحصاءات
  pages/              # الصفحات (الرئيسية، المذاكرة، التدريب، المحاكاة…)
  data/bank.json      # المحتوى المُضمَّن (مُولَّد)
```

## عن الاختبار العام

يقيس الاختبار التربوي العام ثلاثة مجالات رئيسة: **القيم والمسؤوليات المهنية، المعرفة المهنية، والممارسة المهنية**، إضافةً إلى الكفايتين الكمية واللغوية. درجات الرخص: معلم (50–69)، ممارس/متقدم (70–79)، خبير (80 فأعلى). المحتوى هنا اجتهاد تدريبي استناداً إلى بنية الاختبار ونماذجه الشائعة.
